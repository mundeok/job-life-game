# 직업 인생게임 기획서

Nov 20, 2026 · @교사

## 1. 게임 개요

한국의 한 마을에서 태어나 8살부터 생의 마지막까지 살아 보며, 어떤 노력이 어떤 직업으로 이어지는지 경험하는 1인용 직업 인생 시뮬레이션이다.

| 항목 | 내용 |
| --- | --- |
| 대상 | 초등학교 6학년 (실과 진로 단원) |
| 인원 | 1인 플레이 |
| 기기 | 태블릿 (웹 브라우저) |
| 한 판 길이 | 약 40분, 약 60턴 |
| 배경 | 한국 (도시, 농촌, 어촌, 산골 중 무작위 출생) |
| 승패 | 없음. 엔딩에서 칭호와 인생 앨범을 받음 |

핵심 메시지는 세 가지다.

- 진로는 내가 정하고, 노력하면 선택지가 늘어난다.
- 꿈을 이루지 못해도 다른 길이 있고, 진로는 바뀔 수 있다.
- 직업을 가진 뒤에도, 은퇴한 뒤에도 배움과 성장은 계속된다.

## 2. 교육 목표

게임의 진행 순서가 실과 진로 단원의 흐름(자기 이해 → 직업 탐색 → 진로 준비)과 같도록 설계한다.

| 진로 단원 내용 | 게임 속 장치 |
| --- | --- |
| 나의 흥미와 적성 알기 | 육각형 능력치, 숨은 흥미, 성격 카드, 캐릭터의 생각 |
| 다양한 직업 세계 탐색 | 직업 도감, 직업 체험 이벤트, 동창회, 대안 직업 추천 |
| 새로운 직업과 미래 변화 | 시대 변화 이벤트(AI, 새 직업 등장), 숨은 직업 |
| 진로 계획과 준비 | 꿈 로드맵, 진학·자격증 갈림길 |
| 일의 의미와 균형 잡힌 삶 | 삶의 지표 4개, 은퇴 후 재능기부와 봉사 |

지킬 원칙

- 직업에 귀천이 없고, 성별에 따라 직업이 달라지지 않는다.
- 태어난 곳과 재능은 시작점만 다르게 할 뿐, 모든 직업에 도전할 수 있다.
- 죽음, 폭력, 심각한 질병, 이혼, 극단적인 가난, 범죄는 다루지 않는다.
- MBTI는 고정관념과 근거 문제로 쓰지 않고, 강점만 있는 성격 카드로 대신한다.

## 3. 인생 단계와 턴 구성

한 판은 5단계, 약 60턴이며 1턴은 평균 35\~40초로 잡아 총 40분 안팎을 목표로 한다.

| 단계 | 나이 | 1턴의 길이 | 턴 수 | 예상 시간 | 주요 내용 |
| --- | --- | --- | --- | --- | --- |
| 탄생 | 0\~7살 | 생략 | 1 | 2분 | 이름, 성별, 어릴 적 꿈, 성격 질문 5개, 태어난 곳과 가족 분위기, 친구 3\~4명 생성 |
| 성장기 | 8\~19살 | 한 학기 | 24 | 15분 | 활동 고르기, 11살에 꿈 카드, 직업 체험, 숨은 재능 발견 |
| 진로 준비 | 20\~25살 | 1년 | 6 | 6분 | 대학(4년)·직업훈련·바로 취업 갈림길, 군 복무 2턴(남자 캐릭터) 또는 인턴·어학연수·자격증 2턴, 입사 시험 |
| 직업 생활 | 26\~60살 | 2년 | 17 | 12분 | 직업별 미션, 승진, 이직, 시대 변화, 두 번째 진로 |
| 은퇴 후 | 60살\~마지막 | 3년 | 약 10 | 5분 | 재능기부, 제2의 직업, 평생학습, 봉사, 따뜻한 마무리 |
| 엔딩 | - | - | - | 3분 | 인생 앨범, 칭호, 돌아보기 질문 |

진로 준비 기간은 현실에 맞춰 20\~25살(6턴)로 두고, 대학을 가면 보통 26살 무렵 첫 직장을 갖는다.

- 군 복무: 남자 캐릭터는 대학 중간에 2턴을 복무한다. 체력, 꼼꼼함, 인간관계가 오르고, 대부분은 일반병으로 가고, 특기병(조리병, 드론병, 의무병 등)은 관련 능력치가 높을 때 지원할 수 있고 뽑힐 확률도 낮다. 뽑히면 관련 직업 경험이 조금 쌓인다. 운동선수는 국군체육부대(상무)에 들어가면 복무 중에도 선수 활동을 이어 갈 수 있고, 올림픽 메달이나 아시안게임 금메달을 따면 체육요원으로 대체복무를 하며 선수 생활을 계속한다. 아시안게임 e스포츠 금메달을 딴 프로게이머도 같다.
- 군 복무가 없는 캐릭터는 같은 2턴에 인턴, 어학연수, 자격증, 봉사 중에서 고른다. 어느 쪽이든 턴 수와 얻는 가치는 비슷하게 맞춘다.
- 성별은 군 복무 이벤트에만 영향을 주고, 직업 조건에는 영향이 없다.
- 직업훈련이나 바로 취업을 고르면 직업 생활이 더 일찍 시작된다.
- 의사처럼 준비가 긴 직업은 직업 생활 초반에 “수련 중” 상태로 몇 턴을 보낸다.

한 턴은 세 가지로 이루어진다.

1. 활동 고르기: 에너지 안에서 활동 2\~3개를 고른다.
2. 이벤트 카드: 상황 하나가 나오고 선택지 2\~3개 중 하나를 고른다.
3. 결과 확인: 능력치와 삶의 지표가 바뀌는 것을 애니메이션과 짧은 설명으로 본다.

수업이 끊겨도 이어 할 수 있도록 매 턴 자동 저장하고, 이미 읽은 이벤트는 빠르게 넘길 수 있게 한다.

## 4. 캐릭터 시스템

캐릭터는 능력치 6개, 삶의 지표 4개, 숨은 흥미, 성격 카드, 숨은 재능, 태어난 곳으로 이루어진다.

### 4-1. 능력치 6개 (육각형 그래프)

능력치는 흥미유형 6가지와 하나씩 짝을 이루고, 0\~100으로 표시한다.

| 능력치 | 흥미유형 | 올리는 활동 예시 |
| --- | --- | --- |
| 체력·손재주 | 현실형 | 운동, 만들기, 텍밭 가꾸기 |
| 탐구력 | 탐구형 | 과학 실험, 독서, 코딩 |
| 창의력 | 예술형 | 그림, 음악, 요리, 영상 만들기 |
| 배려심 | 사회형 | 봉사, 동생 돌보기, 친구 돕기 |
| 리더십 | 진취형 | 반장, 발표, 동아리 만들기 |
| 꼼꼼함 | 관습형 | 일기 쓰기, 용돈기입장, 정리정돈 |

### 4-2. 삶의 지표 4개

건강, 행복, 인간관계, 돈을 따로 두고, 능력치만 올리고 쉬지 않으면 건강과 행복이 떨어지게 한다. 엔딩에서는 점수가 아니라 문장으로 보여 준다.

### 4-3. 숨은 흥미

자주 고른 활동 쪽으로 흥미가 쌓이고, 흥미와 맞는 직업을 가지면 직업 만족도가 올라간다. 잘하는 일과 좋아하는 일이 다를 수 있음을 보여 주는 장치다. 플레이어에게는 숫자가 아니라 캐릭터의 생각(5장)으로만 드러난다.

### 4-4. 성격 카드

시작할 때 “나는 이런 아이” 질문 5개에 답하면 12장 중 2장을 받는다.

- 모든 카드는 강점만 가진다. 단점을 넣으면 “차분한 사람은 발표를 못한다” 같은 고정관념이 생기기 때문이다.
- 효과는 작게(관련 활동 +10% 정도) 두고, 성격 때문에 막히는 직업은 없다.
- 두 장이 만나면 특별 효과가 생기고, 조합 찾기가 다시 하는 재미가 된다.
- 살면서 경험으로 카드를 더 얻는다. 예: 발표를 여러 번 하면 “용기 있는” 카드를 얻음.

| 카드 | 효과 |
| --- | --- |
| 도전적인 | 새로운 활동 효과 +, 대회 이벤트가 자주 나옴 |
| 신중한 | 실수 이벤트가 적음, 꼼꼼함 + |
| 활발한 | 인간관계 +, 리더십 + |
| 차분한 | 집중하는 활동 효과 + |
| 호기심 많은 | 탐구력과 창의력 + |
| 따뜻한 | 배려심 +, 친구 이벤트 결과가 좋음 |
| 용기 있는 | 도전 이벤트 성공 확률 + |
| 끈기 있는 | 같은 활동을 이어 하면 보너스 |
| 꼼꼼한 | 결과물 평가가 좋음 |
| 상상력 풍부한 | 창작 활동 효과 + |
| 성실한 | 에너지가 조금 더 많음 |
| 유머 있는 | 행복이 잘 떨어지지 않음 |

| 조합 | 특별 효과 |
| --- | --- |
| 차분한 + 용기 있는 | 차분한 발표왕: 발표·면접 이벤트 대성공 |
| 호기심 많은 + 꼼꼼한 | 꼼꼼한 탐험가: 연구 활동 효과 크게 + |
| 활발한 + 따뜻한 | 분위기 메이커: 인간관계가 잘 안 떨어짐 |
| 도전적인 + 끈기 있는 | 포기 모르는 도전자: 실패해도 다시 도전할 기회 |

게임의 어려움은 성격이 아니라 상황에서 나온다. 시간과 에너지가 모자라고, 삶의 지표의 균형을 맞춰야 하고, 누구에게나 고민 이벤트가 생긴다.

### 4-5. 숨은 재능

태어날 때 능력치에 아주 작은 차이(+5 정도)와 숨은 재능 1개를 준다. 재능은 이벤트로 발견되고(예: “그림에 소질이 있대요!”), 해당 활동이 조금 빨리 올라갈 뿐이다. 재능은 씨앗이고 노력이 더 중요하다는 메시지를 담는다.

매우 드물게(0.5%, 약 200판에 1번) “빛나는 재능”(천재)을 가지고 태어난다. 세계관에 “아주 가끔 특별한 재능을 가진 아이가 태어난다”는 설정을 둔다.

| 항목 | 내용 |
| --- | --- |
| 확률 | 0.5% (1% 미만) |
| 효과 | 한 능력치의 성장 속도가 크게 빨라짐, 시작 수치 +15 |
| 특별 이벤트 | 영재원 추천, 신동 신문 기사, 조기 입학 갈림길 |
| 현실적인 요소 | 주변의 기대가 부담이 됨(행복 관리가 중요), 재능을 쓰지 않으면 점점 잠듦 |
| 수집 | 처음 가지고 태어나면 칭호 “빛나는 재능”을 얻고 도감에 기록됨 |

천재도 노력하지 않으면 꿈을 이루지 못하고, 천재가 아니어도 모든 직업에 갈 수 있다. 드물게 나오는 놀라움을 주되, “재능보다 노력”이라는 메시지는 지킨다.

### 4-6. 태어난 곳

네 곳 중 하나에서 무작위로 태어나고, 사는 곳에 따라 처음 접하는 경험만 달라진다. 어디서 태어나도 모든 직업에 도전할 수 있다.

| 태어난 곳 | 먼저 접하는 직업과 경험 |
| --- | --- |
| 도시 | AI 개발자, 크리에이터, 박물관·과학관 |
| 농촌 | 스마트팜 농업인, 식품 관련 직업, 텍밭 |
| 어촌·섬 | 숨은 직업 수산양식 기술자, 해양 관련 직업 |
| 산골·소도시 | 산림 관련 직업, 지역 공무원 |

가족 분위기(운동을 좋아하는 집, 책을 좋아하는 집 등)도 긍정적인 것만 무작위로 주어진다.

## 5. 진로 결정 구조

꿈은 플레이어가 정하고, 캐릭터는 플레이어의 행동을 비춰 주는 “생각”을 말하며, 마지막 결정은 항상 플레이어가 한다.

| 요소 | 역할 | 메시지 |
| --- | --- | --- |
| 꿈 (플레이어) | 목표와 결정, 꿈 로드맵이 생김 | 진로는 내가 정한다 |
| 캐릭터의 생각 | 자주 고른 활동과 흥미를 비춰 줌 | 흥미와 적성을 돌아보자 |
| 재능의 씨앗 | 약간의 개성과 발견의 재미 | 재능보다 노력이 더 중요하다 |

흐름

1. 시작할 때: “어릴 적 꿈”을 하나 고른다. 로드맵이나 효과는 없고, 엔딩에서 “어릴 적 꿈과 실제로 갖게 된 직업”을 비교해 보여 준다. 8\~10살에는 목표 없이 여러 활동을 경험하며 흥미를 탐색한다.
2. 11살: 꿈 카드를 받아 직업 도감에서 꿈을 고른다. 꿈 로드맵과 필요한 능력 힌트가 나타난다.
3. 성장기 내내: 직업 체험, 대회, 멘토를 만나는 이벤트에서 꿈을 바꿀 기회가 온다.
4. 꿈과 행동이 다르면 “캐릭터의 생각” 이벤트가 나온다.
5. 19살 무렵: 능력치가 충분하면 꿈을 이루고, 조금 모자라면 비슷한 대안 직업 2\~3개를 추천받거나 다시 도전한다.

캐릭터의 생각 예시 (꿈은 축구선수인데 독서와 과학 실험을 많이 골랐을 때)

> “나는 축구가 좋아서 축구선수가 되고 싶었는데, 요즘은 과학 시간이 제일 재미있어. 선생님도 내가 의사에 잘 어울린대.”

- A. 그래도 축구선수가 내 꿈이야! → 꿈 유지, 체력 활동 보너스
- B. 의사에 대해 알아본다 → 직업 도감 등록, 꿈을 바꿀 수 있음
- C. 둘 다 할 수 있는 길은 없을까? → 숨은 직업 “스포츠의학 의사” 발견

이 이벤트는 진로를 강제로 바꾸지 않는다. 플레이어가 “내가 말과 다르게 행동했구나”를 깨닫는 자기 이해의 계기가 된다.

## 6. 직업과 꿈 로드맵

직업은 21개로, 흥미유형별로 3\~4개씩 두고 선호 직업 약 절반, 실과 강조 직업과 미래 직업을 각각 약 1/4씩 섞는다. 선호 직업은 2025년 초·중등 진로교육 현황조사(초등 1위 운동선수 14.1%, 2위 의사 6.6%, 3위 크리에이터 4.8%)를 참고했다.

해금 조건은 기본값으로 주 능력치 70 이상, 보조 능력치 50 이상으로 두고, 테스트하며 직업별로 조정한다.

### 꿈 로드맵 예시: 축구선수

꿈 카드로 직업을 고르면 5단계 로드맵이 생기고, 단계마다 능력치와 약간의 운으로 결과가 정해지는 시험 이벤트가 있다.

| 단계 | 시기 | 목표 | 현실 이벤트 |
| --- | --- | --- | --- |
| 1 | 초등 | 동네 축구클럽 가입 | 공부와 운동 시간 고민 |
| 2 | 초등 5\~6학년 | 유소년팀 선발 테스트 | 코치 등장, 탈락 시 재도전 |
| 3 | 중학생 | 중학교 축구부 | 팀 동료와 갈등, 전술 이해 부족 |
| 4 | 고등학생 | 고등학교 축구부·전국대회 | 발목 부상(휴식·재활·무리해서 출전) |
| 5 | 19살 무렵 | 프로팀 입단 테스트 또는 대학 축구부 | 합격 또는 대안 직업 추천 |

이끄는 장치

- 꿈에 도움이 되는 활동에 별 표시를 붙인다. 강요하지 않고 힌트만 준다.
- 코치 인물이 조언하고 다음 목표를 알려 준다.
- “프로 선수까지 40%”처럼 진행률 막대를 보여 준다.

프로가 되면 30대 중반에 선수 은퇴를 하고 지도자, 해설가, 유소년 코치, 구단 직원 중 두 번째 진로를 고른다. 선수 시절에 후배를 챙기거나 공부를 병행했으면 선택지가 늘어난다. 같은 방식으로 21개 직업 모두 로드맵 5단계, 현실 이벤트, 대안 직업을 만든다.

운동선수는 우선 축구와 야구 두 종목으로 하고, 꿈 카드에서 종목을 고른다. 능력치 조건은 같고 로드맵 이벤트만 달라진다(예: 야구는 어깨 부상, 리틀야구단, 고교야구 대회). 수영 등 다른 종목은 나중에 추가한다.

### 프로게이머의 현실적인 요소

게임 속 게임 이름은 실제 게임이 아닌 가상의 이름을 쓴다. 게임을 하면 손재주와 탐구력(전략)이 오르지만, 너무 많이 하면 건강과 인간관계가 떨어지게 해 하루 게임 시간 조절을 고민하게 한다.

| 단계 | 시기 | 목표 | 현실 이벤트 |
| --- | --- | --- | --- |
| 1 | 초등 | 친구들과 게임을 즐기기 | 부모님과 게임 시간 약속하기 |
| 2 | 중학생 | 학교·지역 아마추어 대회 | 밤늦게까지 게임(건강 ↓), 팀 소통 문제 |
| 3 | 고등학생 | 프로팀 연습생 선발 | 공부와 연습의 균형, 손목 통증 |
| 4 | 19살 무렵 | 프로팀 입단 | 합격 또는 대안 직업 추천 |
| 5 | 20대 중반 | 선수 은퇴와 두 번째 진로 | 코치, 해설가, 게임 개발자, 스트리머 중 선택 |

프로게이머는 운동선수보다도 선수 생활이 짧아서, 직업을 가진 뒤에도 다음 진로를 준비해야 한다는 것을 보여 주는 사례가 된다.

### 정치인과 대통령 로드맵

정치인은 다른 직업을 먼저 가진 뒤 도전하는 길이고, 대통령은 그 길의 마지막에 매우 드물게 도달하는 최종 단계다. 학교 수업용이므로 실제 정당이나 정치적 입장은 다루지 않고, 공약·소통·봉사만 다룬다.

| 단계 | 시기 | 목표 | 현실 이벤트 |
| --- | --- | --- | --- |
| 1 | 초·중·고 | 학급 회장, 전교 학생회장 | 공약 만들기, 낙선해도 다시 도전 |
| 2 | 20\~30대 | 다른 직업으로 경력 쌓기(변호사, 교사, 공무원, 창업가 등) | 지역 봉사, 마을 문제 해결 활동 |
| 3 | 30\~40대 | 지역 의원 선거 | 주민 의견 듣기, 다른 의견과 토론 |
| 4 | 40\~50대 | 국회의원 또는 시장·군수 | 약속을 지키기 어려운 상황, 비판에 대처 |
| 5 | 50대 이후 | 대통령 선거 | 매우 드물게 당선, 낙선해도 다른 길이 열림 |

선거 결과는 리더십, 배려심, 인간관계와 운으로 정해지고, 단계가 올라갈수록 합격이 어려워진다. 대통령이 되면 칭호 “나라의 일꾼”을 얻고, 지역 의원이나 시장으로 일한 것도 의미 있는 엔딩으로 보여 준다.

### 직업별 고충

모든 직업에는 보람과 함께 고충이 있다는 것을 보여 주기 위해, 직업 생활 단계에서 직업별 고민 이벤트를 2\~3개씩 넣는다. 고충 이벤트에는 항상 회복하거나 대처하는 선택지를 함께 준다.

| 직업 | 대표 고충 | 고민 이벤트 예시 | 대처 선택지 |

고충 이벤트는 단점을 강조하려는 것이 아니라, “어떤 일이든 힘든 점이 있고 그것을 이겨내는 방법이 있다”는 것을 보여 준다. 직업 도감에도 각 직업의 보람과 고충을 한 줄씩 함께 적는다.

## 7. 이벤트 시스템

이벤트는 활동 고르기, 이벤트 카드, 인생 갈림길 세 종류이고, 이벤트 카드는 100장 이상을 목표로 한다.

| 종류 | 빈도 | 내용 |
| --- | --- | --- |
| 활동 고르기 | 매 턴 | 에너지 안에서 활동 2\~3개 선택 |
| 이벤트 카드 | 매 턴 1장 | 상황 하나에 선택지 2\~3개 (카드를 밀어서 고르기는 선택 사항) |
| 인생 갈림길 | 가끔 | 진학, 꿈 바꾸기, 이직, 은퇴 후 길 같은 큰 결정 |

### 설계 규칙

1. 정답 선택지가 없다. 모든 선택에 얻는 것과 잃는 것이 있다.
2. 조건부 선택지: 능력치나 성격 카드가 있으면 특별한 선택지가 보인다. 노력하면 선택지가 늘어난다는 것을 느끼게 한다.
3. 결과를 바로 보여 준다.
4. 이어지는 이벤트: 오늘의 선택이 몇 턴 뒤에 돌아온다.
5. 나쁜 일에는 항상 회복할 선택지를 함께 준다. 좌절보다 대처하는 법을 배우게 한다.

### 현실적인 요소의 범위

| 넣을 것 | 뺄 것 |
| --- | --- |
| 시험을 망침, 슬럼프, 친구와 다툼, 이사·전학 | 죽음, 폭력, 학대 |
| 부상으로 쉬기, 대회 탈락, 면접 불합격 | 심각한 질병, 이혼 |
| 용돈 관리, 월급과 저축, 경기가 나빠짐 | 극단적인 가난, 사기 |
| 승진 탈락, 이직, AI가 일을 바꿈, 재교육 | 범죄 관련 사건 |

### 단계별 이벤트 예시

| 단계 | 이벤트 | 선택지와 결과 |
| --- | --- | --- |
| 성장기 | 학교에 코딩 동아리가 생겼어요 | 들어간다(탐구력 +5, 에너지 -1) / 친구랑 축구(체력 +3, 행복 +3) / 동아리를 직접 만든다(리더십 30 이상일 때만 보임) |
| 성장기 | 수학이 갑자기 어려워졌어요 | 선생님께 질문(탐구력 +3, 인간관계 +2) / 혼자 끝까지(꼼꼼함 +4, 행복 -2) / 오늘은 쉬고 내일(건강 +2, 다음 턴에 다시 나옴) |
| 성장기 (농촌) | 옆집 할머니가 텍밭을 같이 가꾸자고 하세요 | 같이 한다(체력·손재주 +4, 배려심 +3, 스마트팜 농업인 도감 등록) / 정중히 거절 |
| 성장기 | 직업 체험의 날 | 무작위 직업 3개 중 하나 체험 → 도감 등록, 꿈을 바꿀 기회 |
| 진로 준비 | 고등학교를 졸업했어요 | 대학(4년, 전문 직업) / 직업훈련·자격증(2년) / 바로 취업(돈이 빨리 모임) / 1년 여행(행복 +10, 성격 카드 기회) |
| 진로 준비 | 면접에서 떨어졌어요 | 보완해서 재도전 / 비슷한 직업에 지원 / 잠깐 쉬며 정리(건강·행복 +5) |
| 직업 생활 | 회사에 AI 프로그램이 들어왔어요 | 사용법을 배운다(탐구력 +5, 월급 ↑) / 내 방식을 지킨다(나중에 위기) / AI가 못 하는 일을 더 잘한다(배려심 또는 창의력 +5) |
| 직업 생활 (소방관) | 야간 출동이 많은 시기예요 | 체력 훈련(체력 +5, 건강 -3) / 동료와 교대 조정(인간관계 +3, 꼼꼼함 +2) |
| 직업 생활 (크리에이터) | 영상 조회수가 갑자기 줄었어요 | 새 주제 도전(창의력 +5, 성공은 확률) / 구독자 의견 분석(꼼꼼함 +5) |
| 직업 생활 | 다른 회사에서 함께 일하자는 연락 | 옮긴다(돈 ↑, 적응 이벤트) / 계속 한다(승진 확률 +) / 새 직업에 도전(진로 준비로 잠깐 돌아감) |
| 직업 생활 | 후배가 일을 가르쳐 달라고 해요 | 가르친다(배려심 +4, 인간관계 +3, 은퇴 후 멘토 길 열림) / 내 일에 집중(승진 확률 +) |

그 밖의 특수 이벤트

- 대회·발탁: 학교 대표, 영재반, 유소년 대표 선발
- 좋은 어른을 만남: 멘토 선생님이나 코치가 나타나 꿈에 큰 도움을 줌
- 우연한 기회: TV 출연, 해외 연수, 공모전
- 가족 이벤트(밝은 것만): 동생이 태어남, 이사, 가족 여행
- 시대 변화: 새로운 직업 등장, AI, 기후 변화

## 8. 친구 시스템

친구는 숫자가 아니라 이름과 꿈이 있는 인물 3\~4명으로 등장하고, 나와 함께 나이를 먹으며 각자 자기 인생을 산다.

- 게임 시작 때 무작위로 생긴다. 예: 민준(꿈: 요리사), 서연(꿈: 과학자).
- 친구마다 우정 점수가 있고, 함께 보낸 시간과 선택에 따라 달라진다.
- 연락하지 않으면 우정 점수가 천천히 떨어진다.
- 친구의 인생을 통해 다른 직업을 자연스럽게 알게 된다.

| 시기 | 이벤트 | 배우는 점 |
| --- | --- | --- |
| 초등 | 서연이와 단짝이 되었어요 | 함께하는 활동 효과 + |
| 초등 | 민준이가 전학을 가요 | 헤어짐. 편지를 쓰면 나중에 다시 만남 |
| 중학생 | 친구들 사이에 오해가 생겼어요 | 중간에서 어떻게 할지 고민 |
| 중학생 | 친구가 나와 다른 꿈을 찾았어요 | 각자의 길을 응원하기 |
| 고등학생 | 같은 대회에 나갔는데 나만 상을 받았어요 | 위로와 기쁨 나누기 |
| 고등학생 | 친구가 진로 고민을 털어놓아요 | 배려심 선택지 |
| 20대 | 바빠서 친구들과 연락이 뜸해졌어요 | 관계는 가꿔야 유지된다 |
| 30대 | 동창회 초대장이 왔어요 | 친구들의 직업을 보며 다른 직업 알기 |
| 직장 | 동료와 의견이 달라요 | 사회에서의 관계 |
| 은퇴 후 | 오랜 친구와 다시 만났어요 | 평생 우정이 보상으로 돌아옴 |

동창회 이벤트가 특히 중요하다. “요리사가 꿈이던 민준이는 지금 푸드스타일리스트가 됐어요”처럼 친구의 인생으로 직업 도감이 늘어난다.

## 9. 은퇴 후와 엔딩

60살에 은퇴한 뒤에도 3년에 1턴씩 약 10턴을 플레이하고, 생의 마지막은 무섭지 않고 따뜻하게 다룬다.

### 9-1. 은퇴 후에 갈 수 있는 길

| 길 | 예시 | 이어지는 것 |
| --- | --- | --- |
| 재능기부 | 은퇴한 요리사의 무료 요리교실, 은퇴한 의사의 의료봉사 | 지금까지의 직업 경험 |
| 제2의 직업 | 숲해설가, 문화관광해설사, 박물관 도슨트, 시니어 창업 | 새로운 직업 도감 |
| 평생학습 | 대학 다시 가기, 악기 배우기, 그림 전시회 | 배움에는 끝이 없다 |
| 귀농·귀촌 | 시골에서 텍밭이나 작은 농장 | 태어난 곳으로 돌아가는 이벤트 |
| 봉사·지역 활동 | 마을 도서관 봉사, 등굣길 지킴이, 마을 대표 | 배려심, 인간관계 |
| 멘토 | 후배와 제자 지도 (직업 생활 때 후배를 챙겼다면) | 이전 선택이 돌아옴 |
| 여행·취미 | 세계여행, 등산, 바둑 | 행복, 건강 |

은퇴 후 이벤트 예시: 손주가 내 꿈을 물어봄, 옛 직장 후배가 조언을 구하러 옴, 동네에 스마트폰 교실이 생김, 무릎이 예전 같지 않음(가벼운 운동 / 무리 없는 취미), 옛 제자가 찾아옴(교사였을 때).

건강은 수명이 아니라 에너지로 연결한다. 젊을 때 건강을 챙기면 은퇴 후 할 수 있는 활동이 늘어난다. 수명은 85\~95살 사이로 크게 차이 나지 않게 해 벌칙처럼 느끼지 않게 한다.

### 9-2. 인생의 마지막

병이나 사고 장면 없이 “가족과 친구들 곁에서 편안히 긴 여행을 마쳤어요”로 표현한다. 이어서 가족, 친구, 제자가 한 마디씩 남기는데, 누가 무슨 말을 남길지는 살면서 한 선택에 따라 달라진다.

### 9-3. 엔딩: 인생 앨범

1. 나의 인생 연표: 태어난 곳, 꿈, 진로 변화, 직업, 은퇴 후 길을 나이순으로 보여 준다.
2. 육각형 능력치의 변화: 8살, 20살, 60살의 육각형을 겹쳐 보여 준다.
3. 삶의 지표: 점수 대신 문장으로 보여 준다. 예: “친구 4명과 평생 우정을 지켰어요.”
4. 칭호: 승패 대신 여러 개를 받을 수 있다. 예: 평생 도전자(직업을 세 번 바꿈), 마을의 등불(봉사 시간이 많음), 늦게 핀 꽃(50살 이후 꿈을 이룸), 의리의 친구, 평생 학생.
5. 친구들은 어떻게 살았을까: 친구들의 직업과 인생을 한 줄씩 보여 준다.
6. 만약 다른 길을 갔다면: 내 능력치에 어울렸을 직업 3개를 추천한다.
7. 돌아보기 질문: 가장 잘한 선택은? 다시 태어난다면 무엇을 다르게 해 보고 싶나? 친구의 인생 중 가장 기억에 남는 것은?

마지막 화면에는 “다시 태어나기”와 “직업 도감 보기” 버튼을 둔다. 칭호와 성격 카드 조합, 숨은 직업은 판이 끝나도 저장되어 모으는 재미를 준다.

## 10. 가족

가족은 실과 가정생활 단원과 연결되며, 결혼과 아이는 모두 선택이고 어느 선택에도 불이익이나 점수 차이가 없다.

### 10-1. 원칙

- 결혼은 선택이다. 결혼하지 않은 캐릭터에게도 같은 무게의 이벤트(친구와 여행, 조카 돌보기, 반려동물과의 삶, 혼자 하는 세계여행)를 준다.
- 연애 장면은 넣지 않고 “소중한 사람을 만났어요” 정도로만 표현한다.
- 육아와 집안일은 성별과 상관없이 누구나 고를 수 있는 선택지로 둔다.
- 이혼, 심각한 질병 같은 무거운 내용은 넣지 않는다.

### 10-2. 태어난 가족 (어린 시절)

- 다양한 가족 형태를 긍정적으로만 보여 준다. 예: 조부모님과 사는 가족, 다문화 가족. 다문화 가족이면 “두 나라 말” 재능이 생기고 숨은 직업 통역사로 이어진다.
- 가족의 일 돕기: 부모님 가게, 농사, 배 일을 돕며 직업을 처음 경험한다. 태어난 곳과 연결된다.
- 명절, 가족 여행, 부모님 생신, 동생이 태어남 같은 따뜻한 이벤트.

### 10-3. 가정생활

- 집안일 나누기: 어릴 때는 내 방 정리와 설거지, 어른이 되면 가족끼리 일을 나눈다. 꼼꼼함과 배려심이 오른다.
- 경제 생활: 용돈 → 월급 → 저축 → 내 집 마련을 돈 지표와 연결한다.

### 10-4. 내가 꾸린 가족

| 시기 | 이벤트 | 선택 |
| --- | --- | --- |
| 20대 후반\~30대 | 소중한 사람을 만났어요 | 함께 가정을 꾸린다 / 지금은 나의 꿈에 집중한다 |
| 결혼 후 | 가족이 생겼어요 (출생 또는 입양) | 육아휴직을 한다 / 가족과 나눠서 돌본다 |
| 30\~40대 | 일과 가정 사이에서 고민돼요 | 아래 10-5의 선택지 |
| 40\~50대 | 아이가 꿈을 이야기해요 | 응원한다 / 내 경험을 들려준다. 아이가 내 직업을 잇는 “가업 잇기” 엔딩도 있음 |
| 50대 | 아이가 독립해요 | 뜻뿌듯함과 허전함, 새 취미 찾기 |
| 은퇴 후 | 손주가 놀러 왔어요 | 내 인생 이야기 들려주기 |

### 10-5. 육아휴직과 다시 일하기

일과 육아 사이의 고민은 벌칙이 아니라 고민 이벤트로 넣고, 항상 회복할 길을 함께 준다. 아이를 키우는 캐릭터라면 성별과 상관없이 같은 확률로 겪는다.

- 육아휴직: 그 턴에 승진 확률과 돈이 조금 줄고, 행복과 가족 관계가 크게 오른다. 복직할 때 “다시 적응하기” 이벤트가 나온다. 휴직 때문에 해고되는 일은 법으로 금지되어 있어 넣지 않는다.
- 일을 계속하며 나눠서 돌본다: 바쁘지만 경력이 유지되고 건강 관리가 중요해진다.
- 잠시 일을 쉬다: 가족과 행복이 크게 오르고, 몇 년 뒤 “다시 일하기” 이벤트(재취업 교육, 예전 직장 복귀, 새 직업 도전)가 온다.
- 집에서 할 수 있는 일로 바꾼다: 크리에이터, 웹툰 작가, 프리랜서 같은 새 진로를 발견한다.
- 육아 친화 회사: 직장마다 무작위로 정해진다. 육아 친화 회사면 휴직 불이익이 거의 없어, 개인의 노력뿐 아니라 사회와 제도도 중요하다는 것을 보여 준다.

### 10-6. 직업별 가족 고민

가족 고민은 성별이 아니라 직업 특성에 따라 달라진다.

| 직업 | 현실적인 고민 | 선택 |
| --- | --- | --- |
| 운동선수, 프로게이머 | 선수 생활이 짧고 몸 관리가 중요함 | 은퇴 후로 가정을 미룬다 / 가정을 꾸리고 복귀에 도전한다(출산하면 몇 턴 경기를 쉬고 복귀 훈련) |
| 소방관, 간호사, 경찰관 | 교대·야간 근무 | 가족과 돌봄 시간표를 짠다 / 근무 형태를 바꾼다 |
| 의사, 변호사 | 수련과 준비 기간이 김 | 수련 후로 미룬다 / 바쁘지만 함께 간다 |

## 11. 재미 요소

운 요소와 수집 요소로 다시 하고 싶게 만들되, 돈과 결제는 없고 모든 확률을 화면에 공개해 5학년 수학 “가능성” 단원과 연결한다.

### 11-1. 행운 카드

인생의 전환점에서만 뽑는다. 기본 9번(탄생, 초등·중학·고등 졸업, 20살, 첫 직장, 40살, 은퇴, 75살)이고, 대회 입상·봉사 누적·로드맵 단계 달성·승진 때 추가 뽑기권을 최대 3장 받는다.

| 등급 | 확률 | 예시 |
| --- | --- | --- |
| 일반 | 80% | 용돈, 좋은 책 선물, 맛있는 저녁 |
| 희귀 | 18% | 영재캠프 초대장, 해외 펜팔, 직업 체험 특별 초대 |
| 전설 | 2% | 꿈의 멘토, 재능이 깨어남, 세계 대회 초청 |

한 판에 전설이 나올 확률은 9번 뽑으면 약 17%, 12번 뽑으면 약 22%다. 꽝은 없고 일반 카드도 작은 혜택을 준다. 복권나 도박처럼 보이는 표현은 쓰지 않는다. 천재 재능(0.5%)은 행운 카드와 별개다.

### 11-2. 주사위 판정

시험, 선발 테스트, 선거, 대회 때 주사위가 굴러가고, 관련 능력치가 높을수록 주사위에 +가 붙는다. 노력할수록 운의 비중이 줄어드는 것을 눈으로 보여 준다.

### 11-3. 세계 이벤트와 우연한 만남

- 세계 이벤트: 몇 판에 한 번 “올림픽이 한국에서 열려요”, “AI 붐” 같은 시대 사건이 일어나 관련 직업의 기회가 늘어난다.
- 우연한 만남: 낮은 확률로 유명한 멘토, 캐스팅, 해외 연수 기회가 온다.

### 11-4. 반려동물

입양 이벤트가 나오면 강아지, 고양이 등을 데려올 수 있다. 함께 지내면 행복이 오르고, 산책과 돌보기 활동으로 체력과 배려심이 오른다. 돌봄에는 시간과 돈이 든다는 책임감도 함께 보여 주고, 수의사·반려동물 훈련사 같은 숨은 직업으로 이어질 수 있다. 반려동물과의 이별은 “긴 여행을 떠났어요”처럼 따뜻하게만 표현한다.

### 11-5. 직업 퀴즈

직업 체험 이벤트와 직업 도감에 OX 퀴즈가 나오고, 맞히면 관련 능력치나 행운 카드 보너스를 준다. 예: “소방관은 불만 끄는 일을 한다 (O/X)” → X, 구조와 응급 처치, 안전 교육도 한다.

### 11-6. 타임캡슐

10살에 미래의 나에게 편지를 쓴다(꿈, 하고 싶은 일을 고르거나 직접 입력). 엔딩에서 열어 보고, 어릴 적 꿈과 함께 실제 인생과 비교한다.

## 12. 돈과 경제

돈은 원 단위 금액으로 보여 주고 모은 돈과 빚을 드러내되, 순위나 점수로 쓰지 않는다. 본 게임에 가볍게 넣고(A), 자세한 경제 모드(B)는 본 게임 완성 뒤에 추가한다.

### 12-1. 원칙

- 돈은 삶의 지표 중 하나일 뿐이다. 직업 만족도·보람과 나란히 보여 주고, “돈 많이 버는 직업이 1등”이 되지 않게 한다.
- 투자는 저축, 주식(펀드 포함), 부동산 세 가지만 우선 넣는다. 실제 회사·펀드·코인 이름은 쓰지 않고 “대박” 같은 표현도 피한다.
- 투자 결과의 오르내림 폭과 확률은 화면에 공개한다.
- 빚은 감추지 않고 보여 주되, 갚는 방법과 회복 선택지를 함께 준다. 파산, 사채 같은 극단적인 상황은 다루지 않는다.
- 금액은 게임용 대략값이다. 용돈, 시급, 직업별 월급은 실제 통계를 확인해 data.js에서 조정한다.

### 12-2. 내 지갑 화면

| 항목 | 내용 |
| --- | --- |
| 현금 | 지금 쓸 수 있는 돈 |
| 저축 | 예금·적금에 넣어 둔 돈과 이자 |
| 투자 | 주식·펀드의 지금 가치, 부동산(집)의 지금 가치 |
| 빚 | 학자금 대출, 주택 대출의 남은 금액과 이자 |
| 순자산 | 현금 + 저축 + 투자 − 빚 |

금액은 “1만 2천 원”, “3,450만 원”처럼 읽기 쉬운 한국어 단위로 표시한다.

### 12-3. 시기별 돈 활동

| 시기 | 돈 활동 |
| --- | --- |
| 성장기 (8\~19살) | 용돈 받기, “사고 싶은 것 vs 저축” 이벤트, 저축 목표(자전거, 태블릿 등), 저금통에서 어린이 통장으로(이자 체험), 기부하기 |
| 진로 준비 (20\~25살) | 아르바이트, 학자금 대출(첫 빚), 자취 비용, 첫 월급 |
| 직업 생활 (26\~60살) | 월급과 생활비, 저축·주식(펀드)·부동산 중 고르기, 내 집 마련과 주택 대출, 빚 갚기, 노후 준비 |
| 은퇴 후 (60살\~) | 모아 둔 돈과 연금으로 생활, 하고 싶은 일에 쓰기, 기부 |

### 12-4. 투자 세 가지

| 종류 | 특징 | 게임 속 규칙 (대략) |
| --- | --- | --- |
| 저축 (예금·적금) | 안전하지만 천천히 늘어남 | 해마다 작은 이자가 붙음, 줄어들지 않음 |
| 주식·펀드 | 오르내림이 큼. 오래, 나눠서 하면 평균적으로 늘어남 | 해마다 크게 오르거나 내릴 수 있음. 확률을 공개하고, 펀드는 폭이 작음. 가상 회사 이름 사용 |
| 부동산 (내 집) | 큰 돈과 대출이 필요. 살 곳이 안정되고 값은 천천히 변함 | 집값은 천천히 오르내림, 내 집이 있으면 행복 +, 대출 이자는 매년 나감 |

주식을 한 번에 많이 넣으면 “요즘 주가가 걱정돼요” 같은 고민 이벤트가 나오고, 나눠서 투자하면 칭호 후보 “침착한 투자자”를 얻는다.

### 12-5. 빚

- 학자금 대출과 주택 대출이 주된 빚이다. 남은 금액과 매년 이자를 지갑 화면에 보여 준다.
- 빚이 많아지면 고민 이벤트가 나오고, 지출 줄이기·갚는 계획 세우기·전문가 상담 같은 회복 선택지를 준다.
- 빚을 다 갚으면 칭호 후보 “빚 없는 삶”을 얻는다.

### 12-6. 엔딩에 보여 줄 것

평생 번 돈, 쓴 돈, 모은 돈, 나눈 돈(기부), 남은 빚을 나이별 그래프로 보여 주고, 순위는 매기지 않는다.

### 12-7. 나중에 추가할 경제 모드 (B)

시작할 때 기본 모드와 경제 모드를 고른다. 경제 모드에서는 매년 가계부(수입, 지출, 저축) 화면이 나오고 투자 선택이 더 자세하다. 본 게임이 완성된 뒤에 만든다.

### 13-2. 기술 방식

- HTML과 자바스크립트로 만든 웹 게임, 태블릿 브라우저에서 설치 없이 실행
- 직업, 이벤트 카드, 성격 카드는 데이터 파일로 따로 두어 코드를 고치지 않고 내용을 늘릴 수 있게 함
- 진행 상황과 도감·칭호는 태블릿 브라우저에 자동 저장

### 13-4. 참고 게임과 가져온 요소

진행 방식만 참고하고 이름, 그림, 이야기는 가져오지 않는다.

| 참고 게임 | 가져온 요소 |
| --- | --- |
| BitLife | 턴마다 나이를 먹으며 글과 버튼으로 진행하는 화면 |
| 프린세스 메이커 | 활동을 고르면 능력치가 오르고 직업이 정해짐 |
| 인생게임(보드게임) | 진로 갈림길과 이벤트 카드 |
| 심즈 | 기술을 익혀야 승진하는 직업 시스템 |
| Reigns | 카드를 넘기며 고르는 조작 |
| 80억 분의 1 | 승패 없는 인생, 삶의 지표 4개, 실제 자료를 근거로 함 |
| Real Lives | 태어나는 곳이 무작위 |

직업 설명은 주니어 커리어넷과 워크넷 직업정보를 근거로 작성한다.
